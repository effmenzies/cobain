# Coursework

## Initialisation
- Run the compile.py file
- Bot.retrain() is commented out to prevent re-training of the classifiers and re-creating the DTMs from the data
## File structure
### Data
- Data is stored in the datasets directory
- Serialised models and vectorisers are store in the models directory
- Music data is stored in the music directory
- Transactions are created in-chat and are stored in the transactions directory, under a user's private directory
### Code
- All relevant code is in the root (Chatbot) directory
- Test code from development is in the dev directory
- Code used for evalaution is in the eval directory
